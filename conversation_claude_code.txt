❯ what is jinja                                                                 

● Jinja (specifically Jinja2) is a templating engine for Python. It's used to
  generate HTML (or other text formats) dynamically by embedding Python-like
  expressions and control structures in templates.

  Key features:

  1. Variable substitution - {{ variable }} renders values passed from Python
  2. Control structures - {% if %}, {% for %}, {% block %} for logic
  3. Template inheritance - Child templates extend base templates using {% 
  extends %} and {% block %}
  4. Filters - Transform variables: {{ name|upper }}, {{ items|length }}
  5. Auto-escaping - Protects against XSS attacks by default

  Example in your project:

  In templates/base.html, you likely have something like:
  <title>{% block title %}Spendly{% endblock %}</title>
  {% block content %}{% endblock %}

  Child templates like login.html extend it:
  {% extends "base.html" %}
  {% block title %}Login{% endblock %}
  {% block content %}
    <form>...</form>
  {% endblock %}

  Flask uses Jinja2 by default to render templates with dynamic data from your
  routes.
