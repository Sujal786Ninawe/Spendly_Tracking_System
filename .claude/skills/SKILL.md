# Frontend Design Skill

This skill provides UI/UX design guidance for implementing frontend components in the Spendly application.

## Usage

Use this skill when implementing:
- New page layouts
- Form designs
- Component styling
- Responsive design patterns
- User interaction flows

## Design Principles

1. **Consistency** - Use existing CSS classes from `base.html`
2. **Accessibility** - Ensure forms have proper labels and focus states
3. **Mobile-first** - Design for mobile, enhance for desktop
4. **Feedback** - Show clear success/error states for user actions
